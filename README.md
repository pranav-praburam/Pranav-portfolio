# Pranav Portfolio

A recruiter-friendly personal portfolio built with Next.js, TypeScript, Tailwind CSS, and the App Router.

## Tech Stack

- Next.js
- TypeScript
- Tailwind CSS
- App Router

## Local Setup

1. Install dependencies:

```bash
npm install
```

2. Start the development server:

```bash
npm run dev
```

3. Open [http://localhost:3000](http://localhost:3000).

## Production Build

Run a local production build with:

```bash
npm run build
```

Then start it with:

```bash
npm run start
```

## Customize Content

Update the portfolio content in [app/page.tsx](/Users/lalitha/Desktop/pranav-portfolio/app/page.tsx):

- Replace placeholder links for Resume, GitHub, LinkedIn, and project URLs
- Update the contact email
- Refine the experience and skills sections with your real background

## Deploy To Vercel

1. Push this repository to GitHub.
2. Sign in to [Vercel](https://vercel.com/).
3. Click **Add New Project** and import the repository.
4. Keep the default Next.js build settings.
5. Click **Deploy**.

Vercel will automatically detect the app and handle the build output with no extra configuration.

## Notes

- The site is mobile responsive and uses standard Next.js conventions for easy deployment.
- The current content includes placeholder profile and project links so you can swap in your real URLs quickly.
